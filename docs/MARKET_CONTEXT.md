# 盘面底色（功能分支第一版）

用于辅助日内股指期货人工判断。主界面保留四类信息：中证1000参与度、大小盘15分钟收益差、对应现货15分钟成交活跃度、距最近已确认结构位的距离。前两项共用一份，后两项按IM/IF/IH三行始终并列，无需切换，也不跟随下方图表所选品种改变。下方保留一行商品/国债背景，以及三只ETF资金流、日频净申赎的紧凑表格。完整商品市场资金聚合、期货资金流和科创/创业板广度不在本版覆盖范围。

不改变引擎、正式信号、声音、交易日归属或原有行情门槛。该功能不向账户发出交易请求，不计算综合分或推定胜率。

## 与原工作台同屏及21:9布局

生产页面和预览共用`App`、价格图与机会卡片，没有复制一套业务页面。生产入口为`desk-entry.jsx`，历史预览入口`context-preview.jsx`只传入只读预览模式。`main.jsx`导出共用App；规则、行情健康与正式提醒逻辑保持原有实现。

当浏览器视口宽度至少1600 CSS像素、宽高比至少1.9时，自动使用三栏：左侧主价格图，中间市场背景（IM/IF/IH并列及ETF资金），右侧机会列表。顶部八品种横排，期权环境保留，完整工具比较与事件记录放在下方。去掉原1780像素上限，最大支持3840宽度；主图高度随可用视口调整，机会列表在自己的栏内滚动。较矮的宽屏另有紧凑间距，仍保留源时间、数据日和历史状态。

窄窗口自动恢复上下排版；宽屏条件由浏览器实际CSS视口决定，不读取或修改操作系统显示设置。因此内置浏览器仅占半屏时，应展开浏览器以观察21:9三栏。

## 数据与刷新

- `app/market_context.py` 是独立的只读背景模块，调用官方 Wind MCP CLI；`app/etf_context.py`校验ETF字段、日期与单位。不启动或占用第二个 WindPy 进程。
- 查找官方CLI的顺序：`WIND_CONTEXT_CLI`（指向`cli.mjs`）→ 用户目录`.codex/skills/wind-one-mcp-skill/scripts/cli.mjs` → `.agents/skills/...`。不将本机路径写入产品配置。Node.js与该CLI需在所在机器安装；认证由官方CLI自行读取，不复制账号或Key到repo。
- ETF主力流向使用已验证的官方基金专用CLI：`WIND_CONTEXT_FUND_CLI` → `.codex/skills/wind-mcp-skill/scripts/cli.mjs` → `.agents/skills/...`，参数文件按其契约临时存入该CLI的scripts目录，完成/超时/取消后删除。参数只有标的与字段，不含Key；目录不可写时报告缺失，不绕过权限。日频申赎使用unified CLI的`fund_get_listed_historical_price`。
- Windows/macOS共用该实现。Windows通过隐藏子进程运行Node；本次尚未在macOS实机验证。没有新增依赖或修改锁文件。
- 默认按需刷新，不自动启动收费查询。点击“刷新”触发一轮；点击“盘中更新”后，仅在已有CFFEX交易日历及股票交易时段中每60秒尝试一次。关闭开关停止后续轮询；在途请求正常完成，退出服务时取消并回收子进程。
- 每分钟一批三指数快照及一批ETF主力流向快照；每5分钟额外三次5分钟线查询及一批已监测商品/国债合约快照。日频申赎成功后每自然日只查一次，失败或缺失间隔30分钟再尝试。完整四小时约672次业务查询，另加日频批次，仅为排程估计，不代表HTTP次数、积分或已验证计费。请求串行，单次30秒超时，不立即重试失败批次，不修改WindPy看门狗。
- `WIND_DESK_CONTEXT_DISABLED=1`或原有离线模式禁用背景外部请求。缺少CLI、权限、额度或超时均在面板报告，保留原源时间；不补零、不拼接资金流口径。开关只保留在本次运行，不跨服务重启自动续费。
- `/api/market-context` 只读缓存；POST `/refresh`、`/monitor`沿用本机来源校验。打开更多页面不创建更多采集器；60秒冷却和单在途限制由服务端控制。

## 指标口径

参与度为上涨家数/(上涨+下跌)，相对前收盘，排除平盘。合计必须为1000；数量校验并非逐一成分名单验证。15分钟变化只使用本模块实际保存的同一连续交易时段快照，不回填历史广度。

大小盘偏向=中证1000最近15分钟收益率-上证50最近15分钟收益率，单位百分点。两指数使用相同5分钟线结束时间，且四个价格端点必须完整，禁止跨午休；不解释为机构行为。

成交活跃度=对应现货指数最近三根5分钟成交额之和/过去20个有数据交易日同刻的中位数，至少10个有效基准。金额单位必须明确为元。只使用当前日期以前的基准；缺口不填补。首次运行若没有缓存，需要积累或显式导入历史基准，因此可能显示缺失。价格端点及成交额共用完整窗口，早盘/午后前几根数据不足时保持缺失。分钟线至少在标签后65秒采用，沿用本项目的保守确认思路。

期货位置复用现有state的行情、健康状态和已确认levels，不增加行情查询。只有当前连接、交易中且ready时才计算；显示位于最近已确认价位上/下方多少点，不将其升级为“回踩完成”或交易动作。独立历史预览另有明确的历史位置标签。

跨市场仅含已有watch中AG、AU、SC、T、TL真实合约；有几个显示几个，不代表全商品或全期限国债。每项保留自己的源时间和交易日，源涨跌幅基准按Wind返回口径。成交额在展开信息内展示，是名义累计成交额，不是资金净流入；不将夜盘与日盘不同交易日相加或据此推定股债商品资金轮动。

### ETF资金与日期

只展示中证1000ETF南方512100、沪深300ETF华泰柏瑞510300、上证50ETF华夏510050三个样本，不代表全部同指数ETF。不将两类金额相加或计为买卖信号。

- 二级市场流向：基金专用MCP的“当日主力净流入额”，当日累计、原单位元，显示亿元与每只ETF的源时间。15:00及以后源时间明确标为盘后快照，历史/滞后状态保留。不是全部买卖现金净额，也不推断机构身份；该来源与WindPy MFD_INFLOW_M曾出现差异，本页始终保留MCP口径，不拼接。
- 日频净申赎：unified工具明确支持的`f_mf_netsubamt`，原单位元。只查询当前自然日期以前的日期；非交易日允许服务回溯，但必须从返回摘要确认实际共同数据日，并匹配确切“申赎净流入额（元）”列，不从请求日期推定、不拿“净流入额”字段替代。缺失或单位变化保持空值。
- 日频只展示数据日，不伪造盘中时刻。本机收到时间另存`observed_at`，`published_at`始终为空，页面明确说明披露时刻未核实；不能把它回填为数据日盘中已知。样本审计中该日频字段等于份额净变动×单位净值，非逐笔现金到账。
- ETF局部查询失败不清除指数行情或改动引擎。保留旧值的原源时间/数据日，并标记ETF更新不完整；乱序快照不覆盖较新记录。若日频实际数据日尚未达到已知CFFEX日历的最近完成交易日，视作发布延迟，保留旧日期并间隔30分钟再查询。历史视图不能在`observed_at`之前看到这些ETF观测。

## 本机数据与证据

`data/market-context.json`保存计算缓存（每指数最多2400根5分钟线及500个广度快照）；每次查询的原始结构化响应和实际收到时间另存`data/market-context-observed-YYYYMMDD.jsonl`，供以后研究盘中可见性使用。均被现有data忽略规则排除，不提交授权数据。

历史缓存和观察日志用途不同：终态历史分钟线不等于当时实际收到的数据；导入的终态数据不能冒充历史分钟广度或历史到达日志。财务Key由官方CLI管理，不写到缓存、日志或API响应。

## 隔离预览

不重启8765；使用单独的UI构建与历史缓存。准备脚本接受显式提供的、带哈希的既有研究manifest；校验原始数据哈希，回放原引擎获得历史结构、机会和事件，另导入显式提供的MCP快照。输出`desk-preview.json`，为共用App提供三只股指期货真实5/15分钟线及八品种中已有的快照；未采到的AG/SC、1分钟线、期权盘口明确保持缺失，不模拟。示例中的文件由调用者替换为本机实际文件，不将它们提交Git。

```powershell
.\.venv\Scripts\python.exe scripts/prepare_market_context_preview.py --history <manifest.json> --snapshots <指数MCP响应.json> --cross <期货MCP响应.json> --etf-flow <基金MCP响应.json> --etf-daily <日频MCP响应.json> --output .tmp/context-preview-data
npm run build --prefix frontend -- --outDir ../.tmp/context-preview-ui
.\.venv\Scripts\python.exe scripts/preview_market_context.py --data .tmp/context-preview-data --ui .tmp/context-preview-ui --port 8786
```

预览只监听`127.0.0.1`，不启动Desk或WindPy，不查询外部数据；页面明确标记历史时间，刷新与修改监测合约等按钮禁用，所有写请求返回403。共用App在预览模式不建立实时SSE、不提交遥测或图表补数请求，历史机会静默且按11月13日过滤；可切换原来的品种卡和5/15分钟图表，但背景里三个股指一直并列。历史研究样本只用于看布局和核对口径，不是新回测或收益证明。
