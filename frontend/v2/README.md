# 盘面解说 V2

V2以“结论 → 证据 → 细节”展示原看板的实时缓存，运行于本机8770。原看板仍在8765，两页共用同一个WindPy采集器；不改变正式策略、期权模型或声音提醒。

## Windows 启动与关闭

1. 首次安装仍使用仓库根目录的 `install.ps1`，并登录官方Wind客户端。
2. 双击根目录 `Start Dashboard V2.cmd`。首次启动会自动构建V2；8765未运行时调用原 `start.ps1 -NoBrowser`，已有同仓库后台则直接复用。页面自动打开 http://127.0.0.1:8770/ 。
3. 双击 `Stop Dashboard V2.cmd` 只关闭8770，保留原看板和共享Wind后台。要停止行情采集，另用原 `Stop Dashboard.cmd`。

重复启动会复用现有V2，重复关闭可安全执行。更新V2源码后先关闭V2，再启动即可重新构建；V1代码未变化时无需重启8765。端口被其他程序占用、PID已换成别的进程、依赖缺失或无法核对进程归属时拒绝启停并给出错误，不按端口盲目结束进程。根目录内含空格与中文的路径有Windows PowerShell测试。

PowerShell入口（`-NoBrowser`用于观察和自动验证）：

```powershell
.\start-v2.ps1 -NoBrowser
.\stop-v2.ps1
```

仅构建或以前台方式运行展示服务（需已有8765）：

```powershell
node frontend/node_modules/vite/bin/vite.js build --config frontend/v2/vite.config.js
.\.venv\Scripts\python.exe -X utf8 scripts/serve_dashboard_v2.py
```

前台展示服务用Control+C停止。

## macOS 试用

Mac 试用分支是 `codex/mac-sync-v2`。先用原桌面入口启动 8765。在试用工作目录首次运行 `npm ci --prefix frontend` 安装锁定的依赖，再双击 [Start Dashboard V2 Mac.command](../../Start%20Dashboard%20V2%20Mac.command) 构建并打开 V2。脚本使用 Python 3 标准库。终端也可以运行 `./'Start Dashboard V2 Mac.command' --no-browser`。

重复启动会复用本目录的 8770 服务。关闭 V2 时，在其终端按 Control+C，8765 的行情采集继续运行。

ETF 资金流按缓存的实际频率显示。日内累计使用源时钟判断时效，WindPy WSD 日频截面显示数据日期。日频金额单位缩放仍待核验。

## 数据与文件

- 原版与 V2 共用 `frontend/shared/market-cards.jsx` 及 `frontend/v2/model.js` 的涨跌幅计算。顶部按股指、贵金属、原油、国债分组，卡片同时显示相对前收盘的涨跌幅、五分钟走势、十五分钟结构与合约现价。
- 原版从自己的 8765 读取卡片数据，选中的五分钟图复用已有请求，其余品种串行读取已完成的五分钟线缓存。卡片不登记一分钟图关注、不发起 Wind 查询。V2 的数据入口仍是 8770。
- `scripts/serve_dashboard_v2.py`：只串行GET8765的`state`、`market-context`、`bars`和`events`，不导入Wind、不POST、不增加采集或图表关注租期。
- `/v2-api/health`：仅返回V2身份、仓库路径和进程号，供启动/关闭核对，不读取行情后台。仅本机可访问。
- `data/dashboard-v2/`：本机构建产物、日志和进程记录，已被Git忽略。V2不写`frontend/dist/`。
- `scripts/capture_dashboard_v2.py`：可选的手工只读缓存存档工具；实时页不加载冻结样本，失败也不回退样本。此前`data/commentary-preview/`存档保留。

浏览器每次请求完成3秒后再请求；多个页面共享2.5秒缓存，无页面访问时不轮询。后台盘面背景的监测开关与30秒冷却、ETF至少60秒冷却保持原样。每次最多补读一个合约的分钟线，换合约或交易日清除旧图，图表只显示已完成5分钟线。

主状态HTTP等待最多10秒，浏览器请求最多20秒；独立的15秒行情新鲜度门槛未放宽。后台异常时保留旧画面、暂停结论并灰显，自动重试；个别背景、事件或图表失败单独提示。原后台偶发慢响应仍可能导致短暂重连。

## 展示边界

- 结论→证据→细节：规则摘要、8张分组行情卡、广度差位置条、独立三维证据、ETF明细、机会价格条、30分钟事件、可选结构层与IV−RV。
- 用户附件仅作规则设计参考，不执行附件代码；未沿用缺波动率返回0、投票相消后错称“仅一项支持”等逻辑。缺失就是缺失。
- 广度差±20pp、成交偏向1.15×/其倒数是展示阈值初值，未经历史校准。价格仅显示实际5分钟价差，不冒充标准化显著性。位置条只映射广度差，不是加权风格或情绪分数。ETF绝对净流入不作为跨规模风格确认票。
- 八个品种都用现价与上一完整日盘收盘价计算涨跌幅，卡片标注“较前收盘”。悬停可见基准日期、行情时间和曲线末根时间。迷你曲线取行情源日期上海时间 09:00 起已完成的五分钟线，包含当晚已收盘的 K 线，虚线标出前收盘。缺基准时，涨跌幅显示为“—”。
- 日收益波动标准差、同到期/同口径IV与skew历史分位、全A同刻成交额、涨跌停家数未接入，不用假设值填充。IV低于RV仅是波动差，不表示便宜或交易价值。
- 雷达按绝对距触发/初始风险排序，缺触发价排后；已失效/过期和非当前交易日机会不展示。历史触价明示“历史K线覆盖”，不升级为实时确认，不新增声音。
- 事件使用`known_at`可知时间；历史重建与实时机会事件分开标记。广度升破60%只取同日、间隔不超过90秒的相邻快照，并以5分钟冷却去重，不回填不存在的盘中事件。
- 数据源时间始终保留。行情按15秒及后台就绪状态判断，背景按源时钟判断；5分钟/15分钟指标按完整K线形成节奏判断，不套用报价门槛。缺失或过期数据不参与结论，ETF缺失不补零。午休及收盘切换为明确标注的回顾；独立的“断线演示”按钮仅模拟V2失联，不断开正式后台。
