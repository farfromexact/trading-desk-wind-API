# macOS Wind API 配置验证

日期：2026-11-10（上海时间）。本机 Apple Silicon，项目虚拟环境 Python 3.12.13 arm64，官方 Wind API 26.1.7。

## 配置

`.venv/lib/python3.12/site-packages/WindPy.pth` 指向 `/Applications/Wind API.app/Contents/python`。
使用官方应用中的 `WindPy.py` 及其动态库，没有复制或修改 SDK，也未从 PyPI 安装同名包。
首次调用需完成 Python 接口自己的 Wind 登录；本次另启进程时曾再次要求登录。

## 已实际验证

- `w.start()`：错误码 0。
- `w.wss('000001.SZ', 'sec_name')`：错误码 0，返回“平安银行”。
- CFFEX 交易日历：2026-11-09 至 2026-11-10，返回 2 日。
- 2026-11-10 IM 主力映射：IM2612.CFE。
- IM2612.CFE 09:30–10:00 原生 5 分钟线：错误码 0，返回 6 行。
- 期货快照：错误码 0。
- 期货订阅：错误码 0，5 秒内收到一次成功回调，随后取消订阅。
- 000852.SH 期权链：错误码 0。
- 前端构建通过，10 项图表/品种格式测试通过。
- Python 测试 133 项通过（1 条既有依赖弃用提示），锁定依赖安装完成。
- 看板 HTTP 服务启动成功；行情子进程停留在连接/独立认证阶段，尚未验证整页加载。测试服务已停止，避免 25 秒连接超时后的重启循环。

后续启动观察：浏览器曾显示“Wind 已连接 · 分品种同步中”，出现真实月份合约；随后 API 状态又回到“正在连接 Wind”。说明并非一直无法建立连接，但持续连接和完整加载仍未通过验收，原因尚未确定。不能把全部等待归因为人工登录。

以上为收盘后接口兼容性检查，不代表盘中持续行情、新鲜度、所有品种和所有期权字段均已验收。
受限执行环境下 SDK 曾在写用户目录/启动时异常退出；允许访问 Wind 用户目录和网络后连接成功。

Mac 安装与启动入口：`install-mac.command`、`Start Dashboard Mac.command`。启动器以前台方式运行，Control+C 停止。
若每个新进程都提示登录，可由用户自行在官方登录框选择自动登录，然后再次验证实际看板。未自动修改或保存账号凭据。

## 同仓库配置整理验证

两端安装器现调用 `scripts/configure_wind.py`；它保留有效的已有 SDK 路径，支持显式路径覆盖，并限制只写当前项目虚拟环境。
Mac 本机配置写入和 `--check` 均通过；Shell 启动/安装脚本语法检查通过。
包含新增的路径选择、失效路径恢复与显式错误测试后，pytest 共138项通过（1条依赖弃用提示）。
本机没有 PowerShell，Windows 安装脚本未执行；Windows 路径分支的离线单元测试不等于 Windows 实机验收。
